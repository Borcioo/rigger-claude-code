## Skill triggers

- Load the skill before the first step of its kind; the `superpowers:` rows apply when the
  superpowers plugin is installed:

| Before | Skill |
|---|---|
| dispatching subagents or running agents in parallel (briefs, models, load limit, fix rounds) | `rigger-core:orchestrating-subagents` |
| branching, committing, PRs, merging, releases, tags, changelog, hotfixes, reading history to learn why code changed | `rigger-core:git-workflow` |
| UI components, optimistic updates, per-item action buttons, ARIA, form and consent controls, translated labels, UI tests | `rigger-core:web-ui-traps` |
| writing or restructuring e2e tests, test gates for a task or an agent, a slow or flaky browser suite | `rigger-core:e2e-playwright-speed` |
| choosing, changing or upgrading lint/format/type-check/test tools, a slow phpcs/PHPStan/tsc/ESLint gate | `rigger-core:stack-tooling` |
| new behaviour, a spec or a plan, in a side session too | `superpowers:brainstorming`, then `superpowers:writing-plans` |
| writing code for a feature or bugfix | `superpowers:test-driven-development` |
| a bug, a failing test or unexpected behaviour | `superpowers:systematic-debugging` |
