## Code is written in English (hard rule)

- Every identifier (functions, variables, constants, classes, hooks, option/meta keys, CSS classes,
  file names), comment and docblock is English. This overrides "match the surrounding code": in a
  repo with names in another language, new code is still English; never copy such naming from
  neighbouring code, memory notes or earlier sessions.
- Commit messages and PR titles/descriptions are English too, with no attribution or session-link
  lines.
- User-facing text goes through the project's i18n (English source string plus its translations).
  If the project has no i18n, ask before hard-coding text in another language.
